# 发布内容与隐私检查

本仓库仅公开程序源码、运行所需资源、配套词库、说明文档及发布文件。个人 settings.json、Minecraft options.txt、运行日志、原始采集、截图、本机依赖、开发备份和本机绝对路径不属于发布内容。

0.2.146 发布前扫描了当前源码资源、完整安装包、旧版发布包以及可达 Git 历史文件，检查常见凭据格式、个人路径、邮箱、UUID 和已知玩家名。规则扫描不能保证识别所有未知玩家 ID 或全部敏感数据。

本次将历史提交作者/提交者的个人邮箱替换为账号的 GitHub noreply 邮箱。历史提交编号随之改变；已有克隆需要重新克隆或重新同步。第三方克隆和 GitHub 缓存中的旧提交不受此修改控制。

非官方模组，与Monumenta制作组无关。有机翻内容。
