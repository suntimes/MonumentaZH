# 结构与验证

## 目录

- `src/monumentazh/`：客户端入口、组件翻译、身份保护、采集队列和固定格式规则。
- `src/monumentazh/mixin/`：Minecraft 1.20.4 显示入口钩子。
- `resources/`：Fabric 元信息、Mixin 声明、内置基础词库和按键语言文件。
- `config/monumenta_zh/`：0.2.46 配套补充词库与 NPC/地点名称数据。
- `tests/`：不启动游戏窗口的队列和数量规则测试。

构建只使用开发者自己安装的 Minecraft/Fabric 依赖。当前没有 Gradle/Loom 工程，也没有将 Minecraft、Fabric、Gson 或 Mixin JAR 放入仓库。

## 首次公开前的本地验证

- 新队列的悬浮登记不直接处理书页，每 tick 最多一张未缓存页；54 本副本复用相同内容。
- 5,400 张不同书页的排队与导出完整性、源快照不可变和书页修改识别。
- 原版阅读器、讲台、过滤文本、作者、链接、重载/关闭与原始 NBT 检查。
- 2,215 条删除项由规则逐项覆盖；1,671 个真实组件及 7 个对照，总计 3,893 个组件检查源数据、数字样式、颜色、交互、缓存与关闭状态。
- 302 个最近组件、46 个玩家/私聊保护用例及 63 张任务悬浮卡回归。

上述原始采集、原始日志和测试实例包含本机上下文，不随仓库公开。仓库里的核心测试使用独立构造样本；本地验证不等于实服视觉或 FPS 保证。

## 性能边界

采集按约 2ms 软预算分批，一次翻译不能中途打断，因此单页耗时可能超过预算。相同内容缓存命中和全新长书的耗时不同，不能把副本对照样本直接外推为所有箱子的帧数。

原有脏快照序列化/保存仍为同步操作，主动导出/退出会等待队列完成；本版没有声称消除所有保存尖峰。

## 修改原则

- 保留服务器源组件、NBT、点击/悬浮元数据和可见数字。
- 优先使用完整句子或明确场景规则，不做无上下文的全局单词替换。
- 固定精确译文优先于数量规则；未知物品名保留原文。
- 玩家 ID 保护依场景和组件证据判断，不因与 NPC 同名而全局压制 NPC。
- 新功能仅在缺少配置时使用默认关闭，不重置已有设置及快捷键。
