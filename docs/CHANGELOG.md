# 0.2.168 群岛任务译校与显示修复

适用于 Minecraft 1.20.4 / Fabric。非官方模组，与 Monumenta 制作组无关，有机器翻译内容。

- 累计补充和校对塞尔西亚群岛、雾港任务对白、选项与任务目标；已获取资料仍存在缺页和未确认分支，不代表全服务器完整覆盖。
- 落实审计确认的姓名与对白修订，统一希尔海文·史密斯、卡尔德，修正内应等关键表达。
- 国王谷与塞尔西亚群岛的 Overworld 装备来源统一为“野外”，去除这两类标签的英文括注。
- 补译缓浪港小岛国王悬赏，增加四行提示上下文匹配。
- 累计修复告示牌、书页、菜单、物品数量与系统通告的漏译及重复英文显示，统一大师杰作、猎人和维里迪亚猎枪等术语。

升级：退出游戏，替换旧汉化 JAR，并同步完整包内 config/monumenta_zh 下的 overrides.json 和 names.json，再启动游戏。不要同时保留多个汉化 JAR。保留自己的 settings.json 和游戏设置。

验证：本次审批修订53项原生组件回放通过；此前群岛批次3323项回放通过。已检查文本、样式、原组件与关闭汉化恢复原文。尚未完成全部实机视觉验证。

建议普通玩家下载 complete.zip；独立 JAR 与 SHA256SUMS.txt 一并提供。
